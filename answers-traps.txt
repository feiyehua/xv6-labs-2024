Which registers contain arguments to functions? 
For example, which register holds 13 in main's call to printf?

a0 for the 1st argument, a1 for the 2nd, a2 for the 3rd, respectively.

Where is the call to function f in the assembly code for main? Where is the call to g? (Hint: the compiler may inline functions.)
The compiler lined all calls to f and g.

0x6fe.

What value is in the register ra just after the jalr to printf in main?
3c, as RA, the return address register, stores the return address
